# Color Flood

Free single-file HTML5 puzzle game. Flood-It: paint the board one color in
25 moves, chain 3 wins to grow the grid from 14×14 up to 18×18. One HTML
file, zero assets.

**Play:** https://shuangyueliao.github.io/color-flood/

- Mouse / touch / number keys 1–6, procedural WebAudio sounds
- Capture-count hint badges (toggle with H), streak & best-save saved locally
- Procedural canvas graphics, no dependencies

## Submitting to portals

The game is a single self-contained HTML file, ready for HTML5 game portals
(CrazyGames, GameDistribution, itch.io). Fork/clone and submit.
